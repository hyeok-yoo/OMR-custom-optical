# OMR 채점

**바로 쓰기: https://hyeok-yoo.github.io/OMR-custom-optical/**
휴대폰·태블릿 브라우저로 열고 *홈 화면에 추가*하면 앱처럼 설치됩니다.

종이 OMR 답안지를 휴대폰 카메라로 찍으면 판독하고 채점하는 웹 앱(PWA)입니다.
수능·교육청·사설 모의고사·학원 자체 양식처럼 **이미 쓰고 있는 OMR 카드를 그대로** 인식합니다. 전용 답안지를 따로 인쇄할 필요가 없습니다.

- 판독은 기기 안에서만 처리합니다. 서버가 없고, 오프라인에서도 동작하며, 계정이 필요 없습니다.
- 정답표 사진이나 PDF를 올리면 Gemini가 정답과 배점을 읽어 채웁니다.
- 성명과 수험번호 칸을 읽어서 반 전체를 연속으로 채점하고 CSV로 내보낼 수 있습니다.

## 사용법
1. **설정**에서 Gemini API 키를 입력하고 모델(`gemini-flash-latest` 또는 `gemini-flash-lite-latest`)을 고릅니다. AI 기능을 쓸 때만 필요합니다.
2. **정답** → 새 정답 → *정답표 사진·PDF로 만들기*를 누릅니다. 문제지 페이지를 함께 올리면 `[3점]` 같은 배점 표기도 읽습니다.
   - 배점이 보이지 않으면 비워 둡니다. 이 경우 채점할 때 상단에 안내가 뜨고, 점수 대신 **맞은 개수**만 표시합니다.
3. **채점** → 정답을 고르고 *스캔 시작*을 누릅니다. 상단 검은 마크 줄과 아래 양쪽 모서리 마크가 화면에 잡히면 자동으로 촬영합니다.
4. 결과 화면에서 할 수 있는 일
   - 문항별 정오, 판독 이미지, 확인이 필요한 문항을 봅니다.
   - 문항을 누르면 답을 고칠 수 있고, 버블별 검은 비율도 함께 보입니다.
5. **반 전체 연속** 모드에서는 촬영할 때마다 이름을 읽어 자동으로 기록합니다. *기록 > 반 채점*에서 학생별 점수, 문항별 정답률·선택 분포를 보고 CSV로 내보낼 수 있습니다.

## 판독 방식
마킹 판독은 AI가 아니라 **광학 방식**입니다. 그래서 같은 사진이면 결과가 항상 같습니다.

1. **정합**: 상단 타이밍 마크 줄과 하단 좌우 기준 마크를 찾아 용지를 평면으로 폅니다. 기울기, 90°·180° 회전, 원근을 자동으로 보정합니다.
2. **드롭아웃**: 밝기 기준으로 인쇄 잉크를 찾고, 빨강·분홍 인쇄 버블은 판독에서 지웁니다. JPEG 압축으로 색이 빠져도 견딥니다.
3. **구조 파악**: 템플릿 없이 버블 배치를 직접 분석합니다. 버블 안 인쇄 글자의 생김새를 서로 비교해 구분합니다.
   - 같은 열끼리 닮았으면(①②③④⑤가 위아래로 반복) 객관식 블록입니다.
   - 같은 행끼리 닮았으면(0·0·0 / 1·1·1) 숫자 표기칸입니다. 단답형, 수험번호, 탐구 과목번호가 여기에 해당합니다.
   - 열 길이가 19·21·21로 반복되면 성명 칸입니다. 초성·중성·종성을 읽어 한글로 조합합니다.
4. **판정**: 버블 안쪽의 검은 비율을 재고, 답안지마다 빈 버블 수준을 기준으로 임계값을 자동으로 정합니다.
5. **안전장치**: 결과가 조용히 틀리는 일을 막기 위한 장치입니다.
   - 흐린 마킹, 중복 마킹, 가운데 자리가 빈 단답형은 '확인 필요'로 표시합니다.
   - 블록에서 보기 열이 빠지면 다른 블록의 인쇄 숫자 모양과 대조해 복원합니다. 복원할 수 없으면 해당 블록 문항을 '확인 필요'로 표시합니다.
   - 답란 근처에 판독되지 않은 마킹이 있으면 경고합니다.

### 문항 번호 매기기
- 수능형 국어·수학·탐구 양식은 자동으로 추정합니다.
- 처음 보는 양식은 Gemini가 인쇄된 문항 번호를 한 번 읽습니다. 결과는 양식별로 저장해서 다음부터는 AI 없이 바로 적용합니다.
- *번호* 버튼으로 직접 고칠 수도 있습니다.
- 광학 판독이 불가능한 특이한 양식은 *AI로 직접 판독*으로 처리합니다. 정확도가 낮다는 표시가 함께 붙습니다.

### 정확도에 대해
테스트 범위는 다음과 같습니다.
- 수능형 양식 5종(국어, 수학 2종, 통합과학, 사회·과학탐구)에 마킹을 그려 넣고, 촬영 상황(원근, 180° 회전, 조명 그라데이션, 흐림, 노이즈, JPEG)을 흉내 낸 이미지
- 실제 휴대폰으로 찍은 사설 모의고사 사진

다만 휴대폰 사진은 조명·반사·용지 휨의 영향을 받습니다. 중요한 시험은 판독 이미지에서 '확인 필요' 문항을 한 번 더 확인하세요.

## 개인용 / 학원용
지금 배포본은 **개인용**입니다. 답안지의 성명 칸은 읽지 않고, 채점한 답안지는 모두 본인 것으로 봅니다.
반 전체 연속 채점과 성명·수험번호 판독은 학원용 기능으로 남겨 두었고, `js/app.js`의 `EDITION`(또는 `window.OMR_EDITION = 'academy'`)으로 켤 수 있습니다.

## 이용 기록과 관리자 화면
- 처음 실행하면 이름을 묻습니다. 이름, 접속 시각, 사용 시간(화면이 켜져 있는 동안), 스캔 횟수, 기기 종류만 Firebase에 기록됩니다. 답안지 사진·점수·정답은 전송하지 않습니다.
- 관리자 화면: *설정* 맨 아래 버전 문구를 다섯 번 누르고 관리자 계정으로 로그인합니다. 사용자별 방문 수, 누적 사용 시간, 최근 14일 사용량, 접속 기록을 보고 차단·삭제할 수 있습니다.
- 보안: 일반 사용자는 익명 인증으로 **본인 문서에 쓰기만** 할 수 있습니다. 다른 사람 기록은 읽을 수 없고, 카운터를 줄이거나 시각을 위조하거나 차단을 스스로 풀 수 없습니다. 이 규칙은 Firestore 보안 규칙(`firebase/firestore.omr.rules`)이 서버에서 강제합니다. 관리자 로그인은 별도 앱 인스턴스로 처리해서 그 기기의 사용자 신원과 섞이지 않습니다.
- Firebase 설정은 GitHub Actions 시크릿(`FIREBASE_*`)으로 배포할 때 `js/firebase-config.js`를 만들어 넣습니다. 시크릿이 없으면 이용 기록은 꺼집니다.

## 배포
정적 파일이라 빌드 과정이 없습니다. PWA 설치와 카메라 사용에는 HTTPS가 필요합니다.

- **GitHub Pages**: 저장소 *Settings → Pages → Source*를 **GitHub Actions**로 바꾸면 됩니다. 그러면 `main` 브랜치에 push할 때마다 `.github/workflows/pages.yml`이 자동으로 배포합니다.
- **로컬**: `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속합니다.

## 개인정보
- 답안지 사진과 채점 기록은 기기(IndexedDB)에만 저장됩니다.
- 외부로 나가는 요청은 Gemini 기능을 쓸 때 Google로 보내는 것뿐입니다. 이때 정답표 이미지, 또는 판독된 답안지 이미지가 전송됩니다.
- API 키는 기기의 localStorage에만 저장됩니다.
